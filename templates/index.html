How It Works

Four steps from input to diagnosis

01 / INPUT
🖼

Upload Data

Provide an MRI scan (JPEG/PNG/DICOM) or clinical biomarkers like MMSE, CDR, and volumetric values.

02 / PROCESS
⚙️

Preprocessing

Scans are normalized and resized to 224×224. Clinical values are scaled and encoded for the model.

03 / INFER
🤖

Model Inference

A fine-tuned ResNet-50 (MRI) or feature model (clinical) classifies and returns class probabilities.

04 / REPORT
📋

Diagnosis Report

Results include a label, confidence score, risk tier, precautions, diet tips, and specialist referral.

    Model Architecture

    🖼

    ResNet-50 (MRI)

    Fine-tuned on brain MRI scans. Final FC layer replaced with 3-class head. Input: 224×224 RGB. Trained with AdamW + cosine LR decay.

    📊

    Feature Model (Clinical)

    8 clinical biomarkers fed through a dense network or gradient-boosted classifier. Features include MMSE, CDR, eTIV, nWBV, age, education, SES.

    🔀

    Ensemble Strategy

    Soft-voting between MRI branch and clinical branch. Probabilities averaged when both modalities are available for higher confidence.

    📈

    Training Dataset

    ADNI (Alzheimer's Disease Neuroimaging Initiative) — 2,840 samples. 80/20 train/test split, 10-fold CV for hyperparameter tuning.
