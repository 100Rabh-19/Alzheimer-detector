How It Works

Four steps from input to diagnosis

01 / INPUT
🖼

Upload Data

Provide an MRI scan (JPEG/PNG/DICOM) or clinical biomarkers such as MMSE, CDR, and volumetric measurements.

02 / PROCESS
⚙️

Preprocessing

Scans are skull-stripped, registered to MNI space, and normalized. Clinical values are scaled and one-hot encoded.

03 / INFER
🤖

Model Inference

A fine-tuned ResNet-50 (MRI) or XGBoost ensemble (clinical) runs the classification and returns class probabilities.

04 / REPORT
📋

Diagnosis Report

Results include a diagnosis label, confidence score, risk tier, and stage classification for clinical review.
